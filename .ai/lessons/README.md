# Lesson files

One file per lesson, named `YYYY-MM-DD-slug.md` (lowercase, hyphenated slug). Register each one in `../lessons.md`.

Template:

```markdown
# <Title>

- Date: YYYY-MM-DD
- Context: what was being done (bug, spec, run — link to it)

## What happened
## Root cause / insight
## Rule going forward
```
